Welcome, Operator

This range hosts a set of deliberately vulnerable web assets built for practicing reconnaissance, web application testing, cryptographic analysis, and offensive tooling. Nothing here is a real client system.

There is no navigation menu. Every entry point must be discovered the way you would on a real black-box engagement: passive recon, source review, configuration files, directory enumeration — and don't forget what the server itself tells you before the first byte of HTML arrives.

Rules of Engagement

  • Flags follow the format CTF{...}
  • Submit flags on the CSZone scoring platform, not here
  • Automated scanners are permitted; denial-of-service is not
  • Difficulty increases as you go — some flags require chaining multiple findings together
